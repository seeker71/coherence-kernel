# fourth-arm-bands.txt — the bands proven to cross four-way on the fourth
# kernel (fkwu). fkwu walks the band's source directly, and its Form-native
# self-JIT crystallizes hot pure functions (tags 1-7,12) to NATIVE and melts
# them on cool. One row per band:
#
#   <band-stem> <shape> <expected-verdict>
#
# shape is fks on every row: the band answers one scalar as the last line of
# its output. validate.sh reads columns 1 and 3.
#
# The band file is form-stdlib/tests/<stem>-band.fk (or -band.bml), else
# tests/<stem>.fk; a form-stdlib/seedbank/tests/<stem>.fk is a band home too
# when no tests/ band claims the stem (fourth_band_stem in scripts/fourth-arm.sh).
# The workload is the file list the three walkers receive: every `; preludes:`
# module in declared order, then the band file, which
# fourth_prepare_source_workload composes into one root fkwu walks from source.
# Provenance: every row is gated four-way by validate.sh itself on every
# suite run — the fourth leg's verdict must equal the three walkers' byte
# for byte, and column 3 is the registered verdict the band must answer.
# A band leaves this file when its source moves outside the walker's op
# families, or when its meaning comes home to an organ: sources a door runs to
# their declared answers, and checks the organ makes on its own output as it
# builds.
#
# A band is out of this manifest for exactly ONE honest reason: it uses an op
# FAMILY fkwu does not yet carry (the standing walls below). A *divergence* —
# fkwu has the ops but computes a different answer than Go/Rust/TS — is NEVER a
# reason to leave a band unregistered. That is a correctness bug: one kernel is
# wrong. Root-cause it and resolve to four-way (recipe shape or walker) before
# the work ships; if the fix is a deeper walker-emitter change, the divergence
# is still owned and tracked to that fix, never buried by omission here.
#
# The standing walls (what keeps a band out). The node content-addressing CORE
# (intern_node, make_nodeid, node_children, node_eq, bp, intern_trivial_int) is
# NOT a wall — it crosses four-way.
#   bp-table parity      — flt-bp-node (form-flatten.fk) is a HAND-CODED literal floor; a bp name
#     it lacks folds to the tag-45 string fallback → malformed nodes. Add the name with its EXACT
#     bp_table.go tuple to fold it. NORTH STAR: make flt-bp-node read the full generated bp_table
#     instead of the hand-coded subset.
#   symbol-wire ctor     — recipe_to_bytes / bytes_to_recipe (.fkb wire round-trip).
#   float-NodeID read-back — float-natives needs true f32 NARROWING (the shim does not narrow),
#     IEEE corner exactness (±Inf/subnormals/NaN identity), and the math natives
#     (sqrt/pow/floor/ceil) over the node ABI.
#   field constructors   — field_* native family; best re-expressed over make_nodeid+intern_node
#     (production field work already crosses via the BML DSL).
#   host io family       — broader source-scan + .fkb codec (read/write_form_binary) + corpus reads
#     (read_with_cache / i18n-load) + json codec (json_parse_body/json_response_body).
#   multi-line output    — bands that print mid-walk (fkwu answers one value through fk_pr); the fix
#     is to reshape the band to return a single integer verdict.
#   byte carrier         — string_bytes, string_byte_fold and form_table_text, the host-pool doors
#     Go, Rust and TS carry natively and fkwu's source door does not. A band that only needs a
#     string's bytes reaches them four-way through str-byte-at.fk's str-byte-list.
#   collection door      — substrate_gc. fkwu reclaims by melting its cons arena and smelting dead
#     local strings, and no Form door asks it to.
#
# Carriers the rows below stand on:
#   records   — record_new lowers (form-flatten.fk special form) to a cons-chain packet with a -1
#     blueprint sentinel plus (key value) entries; the emitted fourth walker initializes a distinct
#     negative-even record carrier from it, so record?, record_get, record_set, record_has,
#     record_keys and record_blueprint never collide with ints, lists, nodes or float boxes
#     (fkwu tags 64/65/66/67/68/99/100). Top-level lets in a band source snapshot in source order:
#     record_new keeps shared mutable identity, and reads captured before record_set keep their
#     source-time value.
#   methods   — method_define/method_has ride manifest rows (tags 197/198); method_invoke is a
#     variadic parse shape (tag 199, receiver + name + 242-cell args); the record table grows on
#     demand in both dimensions and its values are melt roots.
#   content address — intern_node (tag 47) scans the live node table and returns the existing cell
#     on a (category, children) shape match; trivial interns (tags 43/46) dedup the same way;
#     node_eq (tag 80) reads as structural identity. The content-address band proves same-shape
#     identity, distinct-shape difference and projections with relative and structural claims
#     only — absolute NodeID inst counts each kernel's parse-time interns and is not portable.
#   BMF cursor — the cursor-based BMF core (one data-driven matcher, grammars-as-data,
#     parsing-produces-recipes, no-sediment backtrack) crosses the emitted fourth arm: the string
#     cursor (char_at/ord/substring) rides the shim string stones (tags 24..29); the parse emits
#     universal recipes through the content-addressed intern arm (intern_node tag 47, bp tag 45,
#     trivial interns tags 43/46, make_nodeid tag 91). intern_node_at rides the fourth-shim image of
#     the carried intern: its returned NodeID is exactly intern_node(cat, kids), and the source
#     attribution feeds only the framebuffer side-map the verdict never reads.
