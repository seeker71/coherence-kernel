# The coherence substrate — how Form meets its environment

Sixteen pages describing the substrate the body stands on: how a recipe reaches the host, what a
resource *is* to Form, what the surface measured when someone last looked, and the design reviews
the body's meaning-space and choice organs passed through. These are **specs, audits, and
reviews**, not teachings — they answer *how does it work*, *what did it read*, and *what did the
board say*, where [`teachings/concepts/`](../../teachings/concepts/README.md) answers *what
stance does the body hold*.

Most of the tissue this directory documents lives as `.form` docs mapping ~1:1 to live recipes (see
[`MANIFEST.md`](../../MANIFEST.md)); these `.md` pages are the prose that surrounds them.
