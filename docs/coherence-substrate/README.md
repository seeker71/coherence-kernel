# The coherence substrate — how Form meets its environment

Eight pages describing the substrate the body stands on: how a recipe reaches the host, what a
resource *is* to Form, where the language and its artifacts stand, and how meaning is held
form-neutral. These are **specs and maps**, not teachings — they answer *how does it work* and
*where does it stand*, where [`teachings/concepts/`](../../teachings/concepts/README.md) answers
*what stance does the body hold*.

Most of the tissue this directory documents lives as `.form` docs mapping ~1:1 to live recipes (see
[`MANIFEST.md`](../../MANIFEST.md)); these `.md` pages are the prose that surrounds them.
