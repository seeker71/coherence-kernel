# Native proof trace

`fkwu` owns source preparation, process supervision, trace admission and terminal rendering. The Rust sibling executes the independent specimen and supplies its real dispatch JSON. This is a proof utility; it does not run the living body on the sibling.

From the repository root, provide one JSON stdin line:

```sh
form-run ./fkwu observe/kernel-trace-run.bml <<'EOF'
{"source":"form/form-kernel-ts/seedbank/python-adapter/examples/python_demo.py","columns":100}
EOF
```

`source` accepts an existing `.fk` or `.py` specimen. `columns` is optional and defaults to 100, with a minimum of 40. The source remains unchanged. A private evidence directory retains exact trace JSON, the rendered panel, process status and cleanup observations. Python input is prepared into a private Form recipe before tracing.

The panel displays the result, exact dispatch counts, one-decimal shares, descending variant rows and targets at **at least 10%** of total dispatches. Shared `term-graphics.bml` owns tones, bars and duration formatting. The reader refuses malformed JSON, invalid counters and variants whose counts do not sum to the observed total. A literal-only program reports zero dispatches without inventing targets. Elapsed display uses the shared duration precision; `trace.out` retains the sibling's full microsecond measurement.

The native source compiler door publishes a reusable `.fk` after successful proof compilation:

```sh
form-run ./fkwu observe/python-specimen-compile-run.bml <<'EOF'
{"source":"form/form-kernel-ts/seedbank/python-adapter/examples/python_demo.py","output":"/tmp/python-demo.fk"}
EOF
```

The output directory must exist. Preparation closes the actual Form dependencies using the shared dependency-line reader, lowers their sections on `fkwu`, and passes one private prepared unit to Rust. The existing Form parser, lifter and emitter supply Python meaning. Canonical ontology bindings own category identity. The file compiler holds UTF-8 source intact in memory. Unsupported compilation refuses before publication, preserving an existing output.

Current observations: `python_demo.py` and its compiled `.fk` both return **40949**, with **16,530 dispatches**, **13 variants** and **five targets**. The literal `42` produces zero dispatches. An unsupported set expression and a missing input both refuse while preserving an existing output. Threshold equality and nonconserving trace refusal are observed independently of the rendering.

The direct `fkwu` Python compiler lane remains open work: its ontology walker import, proof primitives, blueprint globals and a nested compiler closure do not yet close there. Source preparation and presentation are native; compiler execution remains an independent Rust proof. The shell `kernel-bmf-compile` still serves the separate parity suite, whose reference execution and direct Python walker responsibilities require their own observed migration.

The north star is one Form compiler authority that closes on the native walker, with reusable native compilation, complete source identity and the same execution observations. A proof sibling then contributes independent agreement without owning preparation or the public utility.
