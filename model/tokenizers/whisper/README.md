# Whisper multilingual merge ranks

`multilingual.tiktoken` is the OpenAI Whisper multilingual tokenizer data, shared by the native tiny ear and large-v3-turbo. It contains 50,257 byte-token merge ranks. Language and task tokens are derived from the admitted model geometry.

Source: <https://github.com/openai/whisper/blob/main/whisper/assets/multilingual.tiktoken>. Copied as data from the locally cached MLX Whisper distribution on 2026-09-10; no package or interpreter is needed to read it. OpenAI's MIT license is included in `LICENSE`.
