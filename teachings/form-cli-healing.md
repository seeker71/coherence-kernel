# Repair by witnessed replacement

Native authoring is ours to carry, including temporary helpers, measurements,
generators and migrations. `heal guide` reads current Python detours;
`heal guide|<command>` offers a local Form reference and witness without running
the command. Use the reference where it fits, or build and observe the native
equivalent, update callers, and remove the former implementation. Urs does not
need to repeat this direction or approve it again. The practice lives in
[the native agent tools](../docs/form-native-agent-tools.md).

Start with the failing command, its process status, its expected result, and
the exact current source. Freshness reads 31 after bootstrap. A green number
beside a failed process is a refused candidate. A timeout is an incomplete
observation. Source balance, successful execution, and semantic truth are three
separate questions.

Read the filesystem and import chain. An unresolved name can mean a missing
prelude, a typo, a removed interface, or a primitive on another kernel. Search
definitions and callers; inspect git history to learn the intended contract.
Probe a lane before naming it. A missing interface is not repaired honestly
with an invented stub.

Try the smallest structural candidate in a snapshot. A missing closer often
belongs before the next definition or within a let/if/and expression, not at
EOF. Count comments and escaped strings correctly. Reject a candidate that
compiles but changes the expected band. Two functions sharing one name need
distinct names and a regression exercising each one's actual meaning.

Keep expected values and historical observations out of a proposed source
repair. When a replay differs after its corpus changes, the old recording stays
intact. A missing toolchain is an unavailable resource. Neither case becomes
green through changing the expected result.

Collect RAG hits with their source references, then read the current source.
Old examples, git patches, model answers, and adapters are evidence to inspect.
They do not grant execution authority. Preserve failed attempts alongside the
eventual repair so retrieval does not mistake an attractive failed candidate for
a successful one.

Let real progress guide execution time. The dynamic Form supervisor observes
stage and token movement, adapts its next observation, and offers inspection
when output grows quiet. Process liveness alone does not establish semantic
progress. Explicit cancellation preserves both the chosen action and the
observed process-group release. A failed signal is an OS observation, not a
reason to discard a completed trainer's exit record.

Use deterministic Form edits first, then the session learner's serving
adapter, an evaluated compatible adapter, and each eligible native model in
registry order. Every one of them runs inside `fkwu`; a model server is a
dependency to repair at its source, never a route. Read roles, artifact
presence, tokenizer index, seal, and the session lane before building the
native queue. Plan every eligible row: a single-answer-model choice can leave a
ready model untried. Registry membership alone does not make an unwired model
eligible.

Preserve each model's admission, candidate check or refusal, and completion as
separate observations. Starting one native model cannot satisfy another model's
owed attempt. A malformed inventory leaves an evidence gap and keeps the remote
door closed. Every eligible native route either attempts or reports a concrete
inability before the caller's explicit `remote` door may open once. The remote
answer is another local candidate; the same checks apply. Provider absence and
budget exhaustion are observations, not successful repairs.

Accept only a changed production source with a fresh successful band, exact
expected stdout, empty diagnostic stderr, unchanged dependencies and tests, and
unchanged live input since the snapshot. Keep the original bytes and candidate.
Commit with a guarded replacement. Rejected candidates never enter the live
source. Tests in the snapshot remain executable programs, not an OS sandbox.

Store verified before/after examples and their checker contract in local repair
memory. Replay them as proposals and verify them again. They are training
candidates, not trained weights. Promote an adapter only with a compatible base
identity, artifact hash, held-out repair evidence, and a regression comparison.
A corpus-shaped seed proves buffer admission, not repair learning.

When the local learner is enabled, follow each non-evaluation candidate/check
round with an actual optimizer step on its observed outcome. Resume the last
candidate, retain both hashes and the changed tensor names, and verify that
base weights did not change. Validation losses that print equal after rounding
cannot establish zero regression. A candidate update proves learning ran;
serving promotion still owes independent repair evidence. An adapter file left
by an interrupted supervisor does not supply the missing process completion;
rerun and observe a fresh one.

Measure with `heal eval` before treating saved examples as transferable skill.
Keep development, held-out, and correct-control observations separate. A
correct control remains unchanged; an already-passing repair case is an
invalid measurement. Count unresolved semantic defects instead of making the
expected result easier. Include boundary inputs that distinguish plausible
but incorrect fixes, such as positive fractions beside zero. Semantic cases
compile and execute cleanly before generation; the baseline check refuses a
case whose checker does not, before any model cost.

Mark evaluation records at birth and exclude them from learning and replay.
The evaluator retains them under its own report directory, including failures
and the checker contract. It does not train weights or issue an adapter
promotion receipt. Native case evaluation isolates generation from retrieval;
the wider integration suite checks the resource routing that surrounds it.

Treat a timeout as a measured execution path. Retain process boundaries,
monotonic stage times, work counters, termination signals, and the policy's
offered, selected, and applied choices. Keep prompt and answer bytes out of
diagnostic events. Read `heal report|<evidence-directory>` before deciding
whether another attempt should change the budget, resource, or implementation.
Elapsed stage time includes waiting; it does not identify CPU or GPU utilization.

When a trace places most of a timeout in one named stage, search that stage
and its callers for an existing faster path under the same source and model
contract. Session admission uses the batched prefill in
`form/form-stdlib/form-cli-model-generate.fk`, with matching scratch and slice
widths from `form-cli-model-admission.bml`. Keep a faster path only after equal
token/position results and verified resource release. A faster stage does not
prove the model can repair a semantic defect; the full case needs its own
result, and removing one bottleneck can expose the next.

Read a tensor's actual type and select its decoder; a Q4 GGUF can declare
Q4_K token embeddings where a walker assumes the Q8 decoder. Reject nonfinite device values before
fitting, since they can be misread as enormous finite numbers. The
activation-probe witness fits an outcome embedding in activation space; its
updates do not establish next-token or repair-quality improvement.

Read a check's full contract before rejecting its output. A band can print an
observation before its final verdict; a wrapper expecting only the number is
defective. Preserve the observation and verify the documented complete output
and process status.

When moving a helper into the body, load it with its real callers. Two helpers
sharing a function name pass isolated checks while a combined import selects
the wrong one. The healing timing authority carries its own `fhwt-` prefix, and
combined process/learning witnesses read the real reports. A count from an
isolated helper cannot prove integration.
