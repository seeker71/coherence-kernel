# prebuilt/index.txt — the published warm packs, pinned.

# One line per pack: pack <seed digest> <target> <sha256 of the pack's manifest.txt> <mirror> [<mirror>...]
# observe/prebuilt-run.bml publish prints the line to commit; fetch reads the line for the running kernel (its seed digest and
# OS-arch, float_leaf 66) and refuses a manifest that does not hash to it. A mirror is a directory or an http(s) base; the
# objects live there, never in git. A pack that is not listed, or not at any mirror, is simply built.
