# The choice view plays

The glass could show you everything the body was doing and nothing the body was
being asked. `d` opens the choice view. Each point is a question with options
standing under it: what each is worth, a bar of what got taken and what was
turned away, what is still held, and how long the offer has waited. A point
nobody has ever asked reads `--`, never `0%` — dark is not refused.

Under the points, the play: the sequence, its flow, which step is the narrowest
gate, which step is the most restricting. Then the findings, parted so a reader
can see which to nourish and which to heal — gaps and wounds, each carrying what
it asks for in its own words.

It is not only readable. `g` steps the cursor to the next option, `y` takes the
one under it, `w` holds it — the body's third outcome, silence, the offer left
standing. A take or a hold leaves the glass as one command in the choice
publisher's inbox; the choice organ consumes it and republishes the point with
the outcome appended, so the ledger moves in the frame and the next frame shows
it moved. The view itself stays pure — it folds only what the samples carry, so
it costs nothing on a frame that is not looking at it.

Nothing publishes choice points yet. Where the frame is absent the view names
the door that owes it — `door=gift:choice publisher=choice (form-choice-flow
gives one sample per point)` — and the band stands on a fixture of four points,
so it never waits on that landing.

Two things the work found on the way. The help view is at its row budget: at
80x24 one added help row pushes a glossary row off the bottom, and the live-ui
band catches it — the new keys went into the rows that were already there. And
the carrier seam line was still spelling the key list by hand
(`keys=hatomfjskvn`); a key list spelled twice is a key list that will disagree
with itself, so it now reads `keys=hatomfjskvnd ... gyw`.

The most surprising teaching: the shard that renders the choice needed no new
control-state field. The cursor already had a home — the selection the glass
carries for `inspect` — so walking a sequence of choices cost one string, not a
ninth slot in a cell nine call sites construct.

Where witnessed discomfort became gold: `form-glass-frame-work-band` came back
red, and the reflex was to bisect my own diff. Restoring the base tree first
read 20415 against my 24575 — both red, both contended, because a second glass
was standing on this machine and giving into the same frame. The discomfort of
suspecting my own work bought a measured denominator instead of a guess.
