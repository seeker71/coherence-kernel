# Stops become backtrack points

A Form-level stop used to end the process: `str_len` of nothing, a branch on
nothing, arithmetic over a non-number called `exit(1)` on fkwu, and the siblings
panicked to a crash trace. Now `(attempt x)` walks `x` with a recover point
standing on all four kernels (fkwu tag-201 mode 28 under `_setjmp`; Go
`recover`, Rust `catch_unwind` with a quiet panic hook, TS `try/catch`). A stop
inside unwinds to the attempt, is voiced as one organ-health line naming the
recipe that stopped, and the attempt answers nothing. `oac-offer` stands every
offer inside one, so choice, try and backtrack take their next option. BML says
it in its own words: `try e else h`, `choose { ... }`, `x ?? y`.

The same thread opened the doors fkwu lacked. `read_file_bytes` and
`write_file_bytes` were sibling-only, so four-way bands called names that lowered
to nothing; `external-uri-band` spun forever inside sha256's padding loop because
`len(nothing)` answered 0. fkwu carries both doors (modes 26, 27), the siblings
carry `nothing` and `nothing?` natively, Go's `byte_to_str` answers one raw byte,
and `len(nothing)` stops on every arm. The workarounds for the missing doors were
released (`pdf-text-windowed`, the byte-string round trip in `form-fs`), and
`source-artifact-identity-band`, red because it pinned the gap as truth, reads
whole with a file-bytes vouch.

Witnesses, four-way unless named: attempt-band 1023, bml-recover-surface-band
1023, file-bytes-band 127, backtrack-band 255, offer-ack-core 2097151, cursor full
105 (try/choose parity with the source compiler), pdf-text-file 15,
source-artifact-identity 2147483647; drift gates 16383 with kernel conformance.
Deep recursion no longer aborts Go or Rust: Rust walls its stack as fkwu does and
reaches the million levels fkwu reaches; Go walls a count under a raised ceiling.

**Surprise.** The Bash tool's `grep` is ugrep with `-I`: two raw NUL bytes in a
template string made it skip all of `form-kernel-ts/src/kernel.ts`, and "TS lacks
read_file_bytes" was a false reading until `command grep -a` looked. An absence is
only as true as the eye that read it.

**Discomfort to gold.** My own `p-kw` landed a regression on main
(`bmf-prefix-state-band` 262143 → 220935) because five pattern readers did not know
a new tag. The repair did not teach them a tag; it made a keyword a `lit` that
carries a boundary mark, so every reader keeps reading what it always read.
