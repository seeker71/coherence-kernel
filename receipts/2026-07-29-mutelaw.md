# 2026-07-29 — mutelaw: the lane law for the harder case is written, and dark

Following the architecture question, I took my own best reading of it — that money and sex are the two
hardest cases for the body's lane discipline — and went to check whether that discipline is *enforced*
or merely stated. The two cells make the same kind of promise:

- `value-planes.fk` — "which kinds of knowing are measured, which are sensed … so the mind cannot
  reduce the sacred to a metric"
- `energy-center-glands.fk` — "Two resonance lanes, **never merged**: **belief** — the energy-center →
  gland correspondence … **evidence** — measured molecular biology"

Both promises are backed by a band. Only one of them runs.

```
money  value-planes-band.fk          -> 11111   (declared 11111, on Go / Rust / TypeScript / fkwu)
sex    energy-center-glands-band.fk  -> fkwu:603:43: error [unresolved-call] '"Held' … (declared 1023)
```

## The band is not wrong — its runner cannot read it

`energy-center-glands-band.fk` is a real band with a real law in it. Weight 4 of its declared 1023:

```
def ecgb-lane-law-loop(cs) = if nil?(cs) then true
    else if lt(ecg-belief(head(cs)), ecg-evidence(head(cs))) then ecgb-lane-law-loop(tail(cs)) else false;
```

*"for every center the belief lane is strictly below the evidence lane — the correspondence is held,
the biology is measured, never merged."* That is exactly the check the prose promises, written out,
sitting in the tree.

It is written in the **BML brace surface** — `section [form.bml] { def f(x) = … }` — and `./fkwu --src`
parses S-expressions. Every receipt in this repo runs bands with `./fkwu --src` (123 occurrences for a
single band). So the check exists and never executes.

`form/form-cli` — the native agent surface, built from `form-cli-*.fk` — runs these files with rc=0 and
prints nothing. I could not find the invocation that surfaces a verdict, and I looked: no `--` flags in
the binary's strings, no verb list, no receipt anywhere showing a brace band run with a number beside
it. That is the shape of the gap: not a broken band, a **missing door**.

## Why this answers the question that was asked

`core-lexicon.fk` holds 64 words that define themselves, and the `person` family is
`you me we us they it self` — **no `he`, no `she`.** Gender is absent from the ground, not as a stance
but because of a law: the surface is a projection, never the ground. `nl-pivot-es.fk` carries
`masc`/`fem`, `nl-pivot-de.fk` carries `neut`, and all four tongues intern to the SAME pivot node,
*"witnessed by node identity, never by claim."* Gender is a rendering fact, so it lives at the emitter.

The second law is the one that fails here: **lanes kept apart, never merged.** Measured vs sensed is
four-way proven. Belief vs evidence is unproven — and belief-vs-evidence is the harder of the two,
because it is where a correspondence someone holds sacred sits beside a measurement that could be
mistaken for confirming it. The band that keeps them apart is the one that does not run.

## The most surprising teaching

**A check can be correct, well-designed, sitting in the tree, named in a receipt — and mute, because it
is written in a dialect its verifier does not speak.** It is not missing and not broken: `grep` finds
it, review reads it, a reader counts it as coverage. Nothing distinguishes it from an enforced law
except running it. `mutelaw` — 0 hits before this row, as are `dialectdark`, `tonguelocked`.

It is the fourth kind this week and the first that no amount of care in *writing* the check could have
avoided. `understudy` (922) aims a gate at code the run never takes. `sliverproof` (924) measures the
small part and speaks for the whole. `originblind` (925) copies an exemplar correct only where the
ambiguity vanishes. `mutelaw` is none of those: the gate is aimed right, scoped right, written right,
and silent.

## Where discomfort turned to gold

I ran `./fkwu --src` on a brace-surface file while holding a memory that says, in as many words, never
to do that — it can write a stamp-valid poisoned `.fkb` over the brace builder's good cache. I did it
twice before noticing, then swept: 32 cache files created, all removed, tree back to 135 and
`git status` clean. fkwu had marked them REFUSED rather than silently bad, so the hazard my memory
warns of did not fire — but that is the tool being kinder than my method deserved. The reflex owed is
smaller than "remember the warning": **before running a file, read its first line.** `section [form.bml] {`
is visible at a glance and I never looked.
