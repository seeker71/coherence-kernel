# Raw native words and retained blueprint readers

Signed: Codex, with the native-word review board.

The [native accessor](../docs/native-node-accessor.md) gives Form-owned blueprint
runs a full raw-u64 native interface. One 424-byte RAM image serves every layout
in the execution. Its getter returns a word and availability in registers; its
native batch consumer stores words in owned RAM and returns only the completed
count through the tagged seed boundary. C source and the canonical CLI source
closure remain unchanged by this movement.

Blueprint runs carry reader leases. Retirement closes new admission, existing
readers retain the original bytes, and the final release unmaps retired data.
The accessor invalidates released descriptors before surrendering their data
lease. A refused owner close preserves descriptors and callable code. An
admitted close blocks new entry before releasing code and private mappings.
The native consumer retains a valid frame chain around its indirect calls.

The [source-bound evidence](../docs/evidence/fkwu/native-blueprint-layout.json)
holds 98 source/carrier identities through five completed, warning-free child
runs. The accessor execution covers 64 widths, 67 layouts and 68 views; full
unsigned extrema; arbitrary offsets; prefix counts on unavailable queries;
immutable aliases; untouched output guards; retained reads after retirement;
and a saved descriptor call after owner close refuses. All descriptor, payload,
output and native-code mappings release at the end of their owned lifetimes.
The independent review checks 16 exact ADR, BLR and frame instruction encodings.

The existing blueprint and float executions remain clean: 70 real Metal
layouts and 588 exact CPU/Metal float cases. The adaptive word witness covers
all 65 residual widths and pinned 3→61→7-bit generations. The retained warm
measurement observes compact/word CPU projection at 37/31 ms and Metal at
9/5 ms. It preserves complete bytes in both representations; it does not
establish a general speed ranking. Requested extents remain distinct from
16,384-byte host pages and physical residency.

The accessor's unease reports its live views, requested descriptor/output
bytes, native calls and code state. The witness correlates an inbound
retain-reader response, executes both retained views and re-observes their
ownership. A response records an action; fresh execution supplies its result.

Validation: preflight reports no errors, warnings or unresolved calls for the
executed witnesses. The targeted native multi-argument validator returns 63
with exit 0. All 14 drift gates pass, mask 16383, exit 0. The native guide
reports 0 Python implementations, 2 existing invocation candidates and 0
unread paths. Own Memory Glass reports 902K cells, 68 MiB logical columns,
6 MiB identity subset and one missing tensor-owner observation. Counsel
reports 0 orphans and 11/12 unobserved lanes with no standing hearth. The
contribution meter is declared; no percentage is claimed.

The useful surprise is that refusing retirement promises continued ownership.
Examining that boundary exposed premature descriptor unmapping; preserving
the refusal now has a direct native execution witness. A Form-side signal
identity also uses its owner's stable clock identity, independent of record
representation. The exchange stayed grounded through raw bytes and retained
readers rather than a completion label.

The primary shared field still has fixed 2^26-cell capacity. Its next migration
is an identity column behind a Form-owned directory with stable handle meaning.
Native admission must stand before allocation changes, and reference-bearing
columns need root retention and relocation. Cross-process publication, slot
generations, side-table ownership and reclaimable Form metadata remain open.
Current accessor leases serialize within one process and retain released
descriptor mappings until owner close. They accept owner-built descriptors
and code pointers below 2^56; payload words retain all 64 bits. No field reset
or capacity exhaustion is part of this execution.
