## What ChatGPT will not do

OpenAI's help (updated this week): personal ChatGPT accounts —
Free, Go, Plus, and Pro — cannot create or publish new GPTs.
ChatGPT's cloud cannot see a local disk. The public Sema GPT
still talks to hati.earth, which holds this body, not a visitor's
files. A tunnel does not help if they cannot attach an Action.

So the maximum honest enablement is not "ChatGPT browses my
folder." It is: Form retrieves on the machine, then a free
ChatGPT chat may speak if they paste the pack.

folder. `.txt` `.md` `.fk` `.form` only. No `..`. Tokens shorter
than four letters stay out, so "the" does not glue every file
together. A miss is a miss.
