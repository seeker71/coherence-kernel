# Native words and Form-owned blueprint storage

Signed: Codex, with the native-word and artifact review board.

The current [north star](../docs/fkwu-form-native-north-star.md) keeps execution
identities as native 64-bit words and puts storage layout, numeric meaning,
specialization and lifetime in Form. The [status](../docs/fkwu-kernel-status.md)
separates working Form owners from the primary shared field.

The [identity execution](../docs/evidence/fkwu/native-node-word.json) binds
18 actual executions to the current root binary and C source. The generated
coordinate is one u64: format1/package6/level13/type12/instance32, with a
signed63 integer mode. Admission rejects coordinates outside that domain before
claiming an intern slot. Kind-sensitive equality, mapped readers, exact numeric
boundaries and transport consumers preserve their observed behavior.
The identity column occupies 8 bytes; logical node columns occupy 80 bytes.

The [Form blueprint execution](../docs/evidence/fkwu/native-blueprint-layout.json)
binds 96 current source/carrier identities to four warning-free child runs.
All residual widths 0–64 preserve full u64 words. Pinned readers preserve older
immutable generations across 3→61→7-bit replacement, and retired mappings leave
after final-reader release. Blueprint fields of widths 1–64 pass an independent
bit oracle and actual CPU/Metal execution. Seventy Metal layouts include
arbitrary offsets, exact primitive allocation, mixed float fields, raw u64
neighbors, indexed reads and complete untouched output regions.

A primitive requests 8 payload bytes. Nineteen 77-bit complex rows carry
183 payload bytes in place of 912 expanded field bytes. Twelve mixed numeric
131-bit rows carry 197 payload bytes and request 204 bytes of native span.
All-row access coverage independently checks the final-row allocation bound.
The host page reading is 16,384 bytes; requested extents are not physical RSS.

The float owner checks 588 exact CPU binary64 and Metal binary32 projections
for f16, bf16, E2M1, E4M3 and E5M2. Numeric projection preserves signed zero and
representable subnormals and canonicalizes signed quiet NaNs. Raw projection
preserves all original bits. Block scales remain a separate relation.

The warm measurement uses 1,024 batches of 16,384 repeated six-field rows.
Compact storage carries 157,696 payload bytes; word storage carries 786,432.
The retained run measures compact/word CPU at 37/32 ms and Metal at 8/23 ms.
Generated CPU images are 652/412 bytes. Earlier same-session timing samples
varied with host load; these numbers establish one observed workload, not a
general speed ranking. Both plans use bulk calls and keep GPU data resident
through the measured batch. Upload is excluded; program admission is reported separately.

The [canonical artifact](../docs/evidence/fkwu/native-cli-artifact.json) holds
337 original sources, stamp `b1c1e09caa0e65d1`, actual canonical/platform builds,
ordinary Bash installation with no compiler, the behavior proof, 14 artifact
admission cases and [installed care](../docs/evidence/fkwu/native-startup-care.json).
The Form startup emitter preserves both native check-only and generated
compile-source admission. Every owned builder and acceptance process settled.

The current [C census](../docs/evidence/fkwu/c-bootstrap-audit.json) indexes
751 function definitions, 686 distinct function names, 805 top-level declaration
units, 466 distinct globals and 71 local-static units. The active Darwin AST
contains 655 functions and 455 globals. These lexical and AST populations do
not claim semantic proof of every function.

Validation: source/bootstrap and 18 identity executions passed; the targeted
constructor validator returned 31 on Go, Rust and TypeScript, while the bound
direct fkwu execution independently returned 31. This target is not registered
in the validator's fourth-arm list. All 14 drift gates passed, mask 16383,
with real exit 0. The native guide reports 0 Python implementations, 2 remaining
execution candidates and 0 unread paths. Own Memory Glass reports 892K cells,
68 MiB logical columns, 6 MiB identity subset and one missing tensor-owner
observation. Counsel reports 0 orphans; 11 of 12 lanes remain unobserved without
a standing hearth. Contribution share is declared and percentage withheld.

The useful surprise is that the most compact layout is not automatically the
fastest layout. The observed friction became stricter descriptor admission,
exact tail extents, direct native word operations and width-specialized Metal
loads. Form can retain both representations and compare their actual cost.

The primary shared field still has its 2^26-cell capacity and no live
reclamation. Form record metadata remains in the seed arena. Shared raw-u64
accessors, cross-process publication, reclaimable metadata and owned primary
allocation remain the next runtime boundary. No field reset or exhaustion
experiment is claimed by this work.
