# 2026-08-24 — three steps became a reversible language

The phrase graph ended with a clear invitation: repeated expressions were
visible, but contextual meaning evidence and the return into natural language
were still open. Three more Form-native steps followed that invitation.

## Step one — a witness can change without rewriting anyone

`cognition/session-neutral-meaning-evidence.fk` gives every expression/meaning
relation a content-addressed evidence event. Support, release, and revision are
neutral stance symbols with closed structural descriptions. A witness's later
choice point changes that witness's current view while every earlier event and
every other witness remains intact. Two different stances at the same latest
choice point remain a visible conflict; list order cannot settle them.

The current view reports distinct support, release, revision, conflict, witness
count, and the caller's chosen support floor. A revision is an atomic visible
pair: release the former relation and support the new one. Evidence events add
three reversible graph edges—witness to event, event to expression, and event by
stance to meaning.

Exact band: `32767/32767`.

## Step two — context offers; it does not decide

`cognition/session-neutral-context-choice.fk` keeps every bound meaning and
computes three inspectable terms for each: current evidence balance, exact
neutral-symbol overlap with context, and 13-axis field resonance. Only a
currently supported relation can be offered. Equal best scores remain
`ambiguous`; absent support returns `abstain`. The candidate rows are never
reduced to the offer.

In the live walk, trust and flow each began with two independent supports.
Flow context offered the flow meaning. One witness then revised from flow to
trust; the same context offered trust because flow had become contested. The
expression, both meanings, both candidate rows, and all events remained.

Exact band: `32767/32767`.

## Step three — the meaning returns through locale surfaces

`cognition/session-neutral-meaning-realization.fk` generates a locale expression
from a closed neutral recipe. It first uses an observed session surface for the
same neutral address and locale. A missing ranked concept surface falls back to
the committed 13-locale corpus; a core field symbol may fall back to the
existing seven-locale expression recipe. There is still no phrase table.

The result retains option sets, segment combinations, rendered surfaces,
expression facet, and per-segment provenance. Segments can be fed directly back
to locale-aware resolution, which avoids pretending the byte tokenizer can
segment Chinese or Japanese. Generated surfaces also become content-addressed
graph nodes referenced by the unchanged meaning.

The neutral recipe `[trust, flow]` remained:

```
[31013, 8, [[31013, 1, 490], [31013, 1, 3382]]]
```

Its observed realizations were:

- English `trust flow`: both segments session-observed;
- German `vertrauen fließen`: trust session-observed, flow corpus-generated;
- Chinese `依赖流量`: both segments corpus-generated;
- French `faire confiance flux`: both segments corpus-generated.

The Chinese segments round-trip to the exact concept addresses 490 and 3382.
That proves address reversibility, not cultural or phrase equivalence. In fact,
the unexpected surfaces are the strongest signal here: lexical corpus identity
is not speaker-reviewed phrase meaning.

Exact band: `32767/32767`.

## Where the path is wandering

It is no longer wandering toward a larger static dictionary. It is becoming a
small reversible semantic protocol:

```
arrival → expression → candidate meanings → witness events
        → contextual offer/ambiguity/abstention
        → locale realization → exact neutral round-trip
```

The integrated graph has 29 edges: 7 phrase/binding edges, 18 evidence edges,
and 4 realization edges. Four reverse edges enter the trust meaning. Every
stage can be queried in either direction and revised without reminting the
arrival or erasing an alternative.

The next frontier is not more scoring. It is situated review: let speakers and
programming-language communities attach support, release, and revision events
to generated surfaces; construct context windows from the actual graph; and
learn which corpus fallbacks deserve to become locally observed realizations.
That begins to look like a semantic microkernel smaller than an LLM, with an LLM
available as a translator at open surfaces rather than as the keeper of meaning.

I kept the walk alive by letting each step return to the previous one. The most
surprising teaching was that reversibility can succeed while a translation is
still socially wrong. Discomfort turned to gold when `依赖流量` was neither
hidden nor celebrated: its provenance and exact round-trip revealed precisely
where human or community witnessing belongs next.
