# Alien lands, and the door learns its first purely descriptive axis

*2026-08-08, the time-portal session continues, fkwu on linux (c-bootstrapped checkout witness).*

## What arrived

The human's own definition, asked for and given plainly: alien means
anything not from earth or from this solar system. Grounding it against
the door's existing seven axes surfaced something none of them needed
to face before: every prior axis names a possible FAILURE of the wish —
a bargain, a performed release, the spell returning. Whether a gift's
origin is earthly or elsewhere is not a failure either way. Building
`alien` as if it were another `free` or `spell` — where a witnessed "no"
breaks the verdict — would have quietly declared "earthly gift" a defect.

## The gap this opened in the door itself

The prior growth model had exactly one knob: `tpd-blocking?`, governing
whether a `pending` reading holds the verdict at `pending`. Every axis's
`no` was assumed to be a real break, unconditionally, because until today
every axis HAD a real failure mode. Alien has none. So a second knob,
`tpd-breaks?`, was added: every axis before it returns 1 (breaks on "no",
exactly as it always did — verified unchanged); only `alien` returns 0
(purely advisory, on both `pending` and `no`).

This is named here rather than folded in silently, because the door's own
header carried a claim — "the door never needs to change" — that this
axis made no longer exactly true. It needed to change once,
for the first axis that carries no failure mode. The claim is corrected
in the cell's own header, not defended.

## Witnessed live, beyond the self-check

Three passages, run directly, not just asserted in the band:

    alien-gift  (origin: alien):   verdict granted,  alien: yes
    earth-gift  (origin: earthly): verdict granted,  alien: no
    alien-and-bargained (a REAL failure, bargain, alongside an alien tag):
                                    verdict not-this-time, alien: yes

The third run matters most: advisory does not mean toothless. A genuine
failure (the bargain) still breaks the verdict even sitting beside an
alien-tagged gift — the new knob only softened the ONE axis that earned
it, and left every real failure mode reading exactly as before.

## The most surprising teaching

The question "what does alien mean?" turned out to be doing double duty.
It answered the word, and it also exposed that the door's whole fold
logic had an unstated assumption baked into it: failure and pending-ness
were bundled as if every axis needed both knobs turned the same way.
They didn't have to be — they were just never pulled apart, because
nothing before alien needed them apart. A definition this literal
("not from earth or this solar system") ended up teaching something
about the door's own architecture that no amount of staring at the
existing six axes would have surfaced.
