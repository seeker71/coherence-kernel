## Built, not declared

`form-program-image-symbolic-linker.fk` is a pure two-pass Form leaf. Its caller supplies ordered definitions carrying symbolic node, string and image-local function labels. The linker:

- rejects malformed IR and duplicate node, string or function labels;
- resolves every relationship internally, including function roots;
- emits exact numeric `pif-node-row` values and a valid `pif-table-image-from-parts` table;
- refuses unresolved node/string/function/root references, unknown reference kinds and invalid string bytes;
- returns typed `nothing` in the table seat on every refusal, so a partial executable table never escapes;
- accepts different node/function/string arities without reserved grammar seats, a global function table or caller-provided offsets.
