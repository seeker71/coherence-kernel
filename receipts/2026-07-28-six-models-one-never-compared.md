# Six models in one body, and not one comparison between them

*2026-07-28, evening. Asked whether the codegen stack is the right model to
bootstrap a coding reasoning system. The survey stopped being a survey.*

## What the body actually holds

Read today, not remembered. At least six model families cover this territory:

| | class | cell | state before today |
|---|---|---|---|
| A | hand-authored table projection | `cognition/gen-neutral-code.fk` | green, zero learning |
| B | MDL rule induction + memorizer floor | `cognition/neutral-rule-mdl-admission.fk` | **would not parse** |
| C | typed PL skeleton induction | `cognition/native-learned-language-system.fk` | fails — preludes B |
| D | execution-scored program synthesis | `learn/teach-sema-code.fk` | real, band lost in a port |
| E | oracle distillation | `learn/oracle-distill.fk` | 22 lines, a shape |
| F | transformer decode | `cognition/transformer-generate.fk` | inference only, no training loop |

The codegen stack is A. **No comparison between any two of them has ever been
run.** Model selection machinery exists — B carries a mandatory non-generalizing
memorizer competitor that MDL must beat — and A never entered it.

## Healing it, and why balance was not enough

Three closers: one in `nrma-case-compatible?`, one on the `(let gate …)` inside
`nrma-admit`, one in the band.

The first attempt put both cell closers at the ends of their forms. The file
balanced, my counter agreed, and the Go arm **parsed it and crashed** in
`nrma-admitted?` — because the surplus closer at the `(list …)` tail left
`(let gate …)` open, so the whole result list became the let's body and
`nrma-admit` returned the wrong shape. Moving that closer up to line 200 is what
made it whole.

A wrong nesting balances exactly as well as a right one and answers something
else. **The number is the proof; the parens alone are not.** And the number came
back:

```
Go 65535   Rust 65535   TypeScript 65535   fkwu 65535 (exit 0)
```

Its documented verdict, four-way, eight days late.

## What the panel said

Three of four doors answered (`codex` returned empty). They agreed, unprompted:

- **A is not a model.** It has zero induced parameters and no possible held-out
  set. It is an *oracle and environment* — the only thing in the body that
  produces execution-verified pairs in four languages, which is exactly the
  training data B's induction needs and cannot get anywhere else. Keep it; stop
  calling it a competitor.
- **Ranked for bootstrap** (cold start, little data, self-verifying body):
  D first — the scorer is *running the program*, no teacher opinion, no labelled
  corpus. B second — the only class carrying model selection, but it needs
  paired rows, which A makes. Then C, E, F. The transformer is the highest
  ceiling and the worst bootstrap.
- **Two models is a coin flip.** The minimum informative panel is four *roles*:
  ceiling (A), floor (memorizer, or better, retrieval over the 10k-concept
  body), and **two learners of different class** — one selecting by description
  length, one by execution. With one learner you cannot tell "learning works on
  this task" from "this learner works".
- **The confound that voids a four-way** is already named here as corpus row
  921, common-mode: if the held-out rows are generated by A's own tables, then
  B "generalizing" only proves it recovered A's tables. A wins by construction.
  The heal is to draw held-out cases from target-language programs the
  table-author did not write, judged by the external executors — the only judges
  in this ecosystem not written by one mind.

## The most surprising teaching

**The most careful sentence in what I wrote was the wrong one.** I hedged that
the rivals might be broken merely because nobody had touched them lately —
scrupulous, fair, and dissolved by a single `git log`. It was never a stale
witness. It was a permissive-reader fossil.

And underneath it: the body's strongest **selection** organ (MDL with a
mandatory memorizer floor) and its strongest **witness** organ (emit the code
and run it through a real compiler) have sat eight days apart in the same tree
and have never met on one task.

## Where discomfort turned to gold

Calling a sibling's witnessed band false felt like an accusation, and the pull
was to soften it — "stale", "needs re-proof", "pending". The way through was not
softening but localizing: one commit, born unbalanced, error arithmetic matching
exactly (2 in the cell, +1 in the band = the 3 the band reported). Once it was a
mechanism instead of an accusation, it was fixable in an hour, and the fix
returned the exact number the header always claimed.

## Frontier question

*What does a claimed verdict need to carry so a stricter reader can retire it?*
→ **witness-identity**. The `.fkb` cache learned this in v5 as builder identity;
header verdicts still carry no mark of which reader, at what strictness, granted
them. Corpus row **925** — renumbered from 922 at the second reunion of the day,
per the row-719 anastomosis pattern; sibling sessions landed `understudy` 922,
`overfine` 923 and `sliverproof` 924 on main while this branch worked.

Corpus band `32767`, 320 rows.
