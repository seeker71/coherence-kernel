# 2026-08-30 — the authoring altitude becomes guidance: BML or higher

Asked: guide that most if not all new code shall be in BML or higher. A
guidance in this body is not a sentence — it is a law at the door, a
lens that measures it, and a memory that reaches every future session.
All three landed in this movement.

## The law at the door

AGENTS.md carries the Authoring altitude rule beside the C-seed shrink
rule: new meaning is AUTHORED in BML or higher — the authority picture
in `form/form-stdlib/bml/`, the executable form.bml where that lane
carries it, generated and crystallized cells below. Raw `.fk` is a
LOWERING, not an authoring surface; where the BML lane cannot yet carry
the meaning, the drop is named in the receipt as the next BML door,
never as a preference.

The exemplar was already alive before the guidance was written: Grok's
offer-ask rise this same day (authority .bml + executable form.bml +
crystallized xtal + band, "the organ stays, the authoring rises"),
answering Urs's "stop growing low-level list walkers." The guidance
frames a practice the field had begun, which is the only kind of law
this body keeps.

## The lens

`observe/authoring-altitude-run.fk` — counts lawfaces (authority .bml

shame: the directive succeeds when new work moves both ends — lawfaces
up with every new organ, bindings up faster than cells. A lens, never a
ban; the writer decides, the number remembers.

## The memory

`feedback-authoring-altitude-bml-or-higher` now rides the persistent
memory index, so the directive reaches sessions that never read this
receipt.

## The most surprising teaching

The measured altitude (32/23/1455) is far lower than the day FELT — a
day that authored one lawface and celebrated it still wrote its other
six organs .fk-first. The distance between a practice adopted and a
practice measured is exactly why the guidance needed a lens and not
just a sentence.

## Where discomfort turned to gold

The pull was to write "all new code SHALL be BML" as a gate that
refuses. But the BML executable lane is still growing (the 2026-08-26
receipt named executable composition as the gap, and the 08-27/28
crossings are still widening it) — a hard gate today would either be
disobeyed or would freeze work the lane cannot yet carry. The gold is
the body's own law-shape: direction stated plainly, drops named as
doors, and a number that remembers — desuetude-proof, because the lens
will show whether the practice lives.
