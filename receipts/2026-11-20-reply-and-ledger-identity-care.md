# Reply grounding and ledger identity care

This movement repairs two different sources of unsupported claims: a ledger
reader treated an importer's naming convention as universal identity, and the
companion supplied ambiguous provenance and execution scope to native generation.
It adds no language rejection, reply classifier, automatic answer rewrite, permission
step, generation gate or decoder change.

## Companion evidence

The source changes preserve the distinctions the actual answers need:

- Retrieval presents the matching source line when available and describes a
  match as a candidate, rather than certifying its relevance or supplying facts
  about the person.
- Conversation records preserve exact words, generation status and model
  attribution. An earlier generated assertion supplies no independent factual
  support. Zero supplied turns are explicit instead of silently omitted.
- Absent archive, restore and training-worker steps belong to the named
  companion orchestration source. They do not describe every effect of a model
  operation, the process, the caller or the host.
- Runtime evidence can include local transport files, conditional attempts to
  retain native operation requests/results, and execution metadata. A separate
  conversation journal is only one possible write path. Operation-text records
  and request metadata have separate owners and content descriptions.
- Unobserved access, copying, erasure, current operation trace and release stay
  unobserved. Future release is an attempt whose result arrives afterward.
- The owned native route's existing local-file read interface is described as
  an available capability. Not having inspected the caller or host does not
  establish inability to inspect a selected file. No new read or write authority
  is introduced by describing that interface.
- The shared covenant and encounter teaching preserve the source's subject,
  owner and scope. Appreciation can meet what was actually shared, while
  invited fiction remains free to invent within its fictional frame.
