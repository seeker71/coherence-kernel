# Native source queries enter ordinary review

Signed: Codex. Witnessed 2026-09-17 on `fkwu`; C seed unchanged.

Catalog review requests now accept `source_queries`. The caller selects a
read-only native tool and string arguments; Form obtains the observation from
the resident source documents. Output, exit status and diagnostics travel
together into the initial model context. Expected output and replacement stdin
cannot be supplied as query fields. Partial excerpts leave full source access
open, and the original source/report assertions remain authoritative.

remaining only an assessment artifact. The current caller chooses queries on
resume; omission clears earlier selections. Checkpointing retains commands,
and admission recomputes observations from current resident documents.

## The guidance experiment that was not retained

A separate variant added instructions to complete useful reasoning now and use
native reads for missing facts. With the question, excerpts and checks held
fixed, it requested three full documents and had produced no completed answer
after 666956 ms of observed runtime. The coordinator stopped owned PID 62682
after recording the regression through the diagnostic control exchange. The
process exited 143; no completed model-release receipt or semantic verdict is
claimed. Its prompt and partial tool replies remain retained.

That guidance change was reverted before the ordinary-path trial. The result
does not show that initiative is undesirable: it shows that this wording did
not establish useful completion within the observed cost. The next response
repair needs to address the actual unsupported interpretation and deferred
action, while preserving the original enquiry and sources.
