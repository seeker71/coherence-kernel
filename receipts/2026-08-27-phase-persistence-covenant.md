# 2026-08-27 — the phase persistence covenant: what crosses a restart, what must not

Grounded in cognition/concept-crystallization-contract.fk: gas/water/ice
are REVERSIBLE STATES available to a node, not node kinds. So the question
"which nodes do we persist" dissolves — you never persist a state; you
persist what lets the state be RE-EARNED, and you release everything whose
truth depended on the process that just died. Each rule below stands on a
witnessed defect from this week.

## PERSIST (the claim side — cheap, content-addressed, replayable)

  IDENTITY BY CONTENT, NEVER BY INDEX. An interned node's index is
  process-local; persisted, it aliases to different code next boot and
  answers wrongly under route "native" — the no-signal failure (epoch-ABA
  finding, #533's pair identity). Persist the PROGRAM and the flattened
  identity inputs; the key is reborn by interning, exactly (#523's law:
  persist the program, rebirth the key).

  WITNESS BESIDE CLAIM. A band verdict, a birth receipt, an image-id fold,
  a ledger row — the evidence that ice EARNED its state. Ice without its
  witness rehydrates as a story (greenfiction across a reboot).

  THE SPOOL AND THE LEDGERS. Append-only text IS the journal; crash
  recovery is a fresh reader at mark zero (#549/550 — replay is the
  restart story, not a special mechanism).

  WEIGHTS, CORPORA, RECEIPTS. Already files, already content-named, the
  proven home (every adapter round this week).

  HEAT AS A COARSE TIER, NEVER A RAW COUNTER. Mid-decay counters encode
  process time that stopped meaning anything at exit; persist hot/warm/
  cold so hysteresis resumes honestly without inventing a clock.

## RELEASE AT EXIT, ALWAYS (the capability side — heavyhome)

  MAP_JIT pages, retained handles, KV state, intern indexes, open fifos,
  resident model context. Cheap to keep, ruinous to move — and every one
  is rebirthable from the persisted side in ms-to-seconds (once-born:
  8ms; fifo: mkfifo; KV: re-prefill from the kept token history). A
  serialized capability is a stale ABI waiting to answer (the jitabi
  seam; the kernel-stamp partiality is named in jit-meaning-epoch).

## THE RESTART IS A MEMBRANE, NOT A RESUME

  Recompute the meaning epoch FIRST (jme-epoch over the prelude closure +
  kernel stamp). The world may have changed while the process was down —
  a restart that trusts yesterday's epoch is the .fkb mtime bug at
  process scale. Then:

    ice   whose meaning held: eligible for LAZY rebirth — the first
          request re-crystallizes it (heat-gate pays the birth exactly
          once; nothing rebirths unrequested)
    ice   whose meaning moved: dissolves COUNTED (stale, not corrupt) —
          the membrane's ledger row is the difference between pruning
          and amnesia
    water: resumes as its persisted claim + witness; its bindings
          re-resolve by content — never by remembered seat (fixed-seat
          law, #541)
    gas:  persists as ROWS ONLY (corpus text). Gas re-earns residence by
          heat like everything else; auto-rehydrating speculation is
          zealloop across reboots.

## WHAT IS HEALTHY, in one line each

  Keep claims, witnesses, journals, weights, and coarse heat.
  Release every capability instance and every process-local number.
  Let the first request after restart pay each rebirth, once, visibly.
  Count every dissolution the membrane performs; silence there is the
  only unhealthy option.
