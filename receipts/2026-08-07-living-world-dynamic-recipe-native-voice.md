# Dynamic Recipe execution and the first consented native text surface

Date: 2026-08-07

The previous lens movement could carry an exact Recipe and execution receipt,
but the Recipe itself only ran as a separate source witness. This movement
places execution inside the living Form field and uses its admitted result as
the referent for a locally rendered text surface. No remote model, imported
answer table, model promotion, or C runtime growth enters the path.

## Dynamic Recipe execution

`living-world-recipe-execution.fk` uses the existing Form-native
`form-eval-full.fk` evaluator as a named minimal execution interface. An
`LWRE-RECIPE` contains exact source, evaluator/effect/source-budget contract,
evidence, and path. Its contract identity names the implemented arithmetic,
comparison, logic, control, and user-function surface and explicitly states
that it has no host, file, or network effect.

The contract is not hidden capability. Source length must fit the sender's
positive offered budget. The current evaluator is not gas-bounded, so
nonterminating user recursion remains a real supervision boundary. A completed
trace never fabricates a timeout; sender-authored expiration/default semantics
remain in `offer-ack-core.fk`.

The evaluator's historical source literal `nothing` means numeric zero. That
would violate the living channel's distinction among immediate absence, zero,
and expired-to-nothing. Executable Recipes therefore reject that token before
evaluation. This is an explicit semantic membrane, not a claim that the older
evaluator has already healed its literal model.

`LWRE-TRACE` retains declaration, exact lens, Recipe, before-state, primary
numeric result, alternatives, unknowable remainder, open choice, flow, changes,
all active attribution witnesses, evidence, and local path. Execution is only
an observation. A candidate is governed by every current Recipe, declaration,
and input holder; admission re-evaluates the Recipe, requires byte-identical
trace identity, and crosses the ordinary unanimous offer/ack membrane.
Revocation of any dependency makes the old trace and proposal stale.

The focused witness dynamically evaluates a runtime source Recipe to `49`,
preserves one alternative plus an explicit unknowable remainder, derives three
distinct attribution witnesses and two governing participants, waits without
responses, integrates only after both active acknowledgements, and refuses an
unheld/forged execution path.

## First native text surface

`living-world-native-voice.fk` contains no words, language names, vocabulary,
grammar rules, or answer rows. `LWNV-SYMBOL` is an offered binding from an exact
referent to an offered non-negative position and exact surface segment. The
emitter receives only an authority-minimized capability context, selects active
symbols for the executed referent, orders them by offered position, refuses an
ambiguous duplicate position, and joins their exact segments in Form.

`LWNV-UTTERANCE` retains the integrated execution basis and its trace,
referent, ordered symbol sequence, native rendered string, minimized context,
alternatives, unknowable remainder, choice, witnesses, evidence, and path. It
does not become field authority merely because it can render. Every current
execution-basis holder, symbol holder, and voice-capability holder governs the
utterance proposal at a separate unanimous boundary.

The witness offers two surface cells from two separate sources. They compose
the executed referent `49` into `forty-nine` entirely inside Form. Five holders
govern integration. Revoking one symbol's voice grant makes the old capability
context and proposal stale while leaving the historical utterance inspectable.
With no authorized symbols, the emitter returns honest absence.

This is native composition-to-text, not yet a native generative mind. The test
surfaces and positions are consented fixture offers rather than learned
vocabulary. Autonomous induction of symbol bindings, ordering/grammar
relations, and utterance plans from recurring experience remains pending.

## Next ground

The next movement is not a larger fixture vocabulary. It is to let recurring
consented experience propose symbol↔referent bindings and relative-order
relations, preserve conflicts and uncertainty, and make their admission and
release follow the same living field. Only then does native voice begin to
grow rather than merely render what participants already placed.
