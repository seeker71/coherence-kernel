# Identity-space answer kernel — witnessed

Asked by Urs on 2026-07-26: expand the core axioms into a compact identity
space that can route fundamental questions, give each answer a symbol, admit
more words without changing core identity, and distinguish timeless structure
from time-based logic, reasoning, and knowing.

## What was built

- `cognition/identity-space-answer-kernel.fk`
- `cognition/tests/identity-space-answer-kernel-band.fk`
- `teachings/identity-space-core.form`

The composition is:

    3 identity modes * 7 layers * 7 inquiry planes = 147 timeless addresses
    3 viewpoint roles * 147 addresses = 441 role-qualified positions

Each address has both a minimal local slot (1..147) and a package-qualified
canonical symbol. Each situated question carries subject, claim, time, point,
belief witness, grounding epoch, uncertainty opinion, and reasoning fuel.

The selected acknowledgement is exactly one of:

    nothing | 0 | 1 | derived-node

The recursive node is deliberately separate from the semantic symbol.
Freshness is deliberately separate from both.

Freshly-known response symbols can collapse into one order-independent
constellation. The collapse sorts and deduplicates members before forming the
structural symbol, so permutations share one representative while the members
remain recoverable. It is a commutative quotient only where the relation has
been explicitly declared commutative.

ME/SELF, YOU/ADDRESSED, and IT/REFERRED are an orthogonal viewpoint axis.
AND is canonical constellation union. NOT is set difference inside a supplied
universe; it is never treated as an absolute identity. The witness proves that
`NOT(ME) = YOU AND IT` only in the explicitly closed universe
`{ME,YOU,IT}`, and stops equating them when the universe gains another member.

## Honest boundary

This is an answer-address and receipt kernel, not a native natural-language
answer generator. It can tell where an answer belongs, whether a proposed
symbol matches, how the answer was derived, and whether its proof is fresh.
It cannot produce unobserved empirical content by naming a coordinate.

Time and point are carried but not externally authenticated in this first
slice. The existing native derivation receipt protects its own composition,
not the caller's clock or location claim.

Chinese writing motivated the compact-composition question but is not treated
as generally unordered. Modern research describes Chinese compounds as
compositional and gives reversible pairs whose meaning changes with order
(蜜蜂 "honeybee" versus 蜂蜜 "honey"). The constellation quotient is therefore
an explicit kernel relation, not a generalization about a language:
https://pmc.ncbi.nlm.nih.gov/articles/PMC12325552/
