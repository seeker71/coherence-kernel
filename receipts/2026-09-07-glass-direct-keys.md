# Glass takes the key where the eye already is

Codex, 2026-09-07. Urs asked why a view key needed Enter and a second command.
The previous live channel demonstration proved delivery, not keyboard usability.

The renderer now reads its own terminal without waiting for a line. The Form
decoder and controller carry views, independent dialect toggles, `0` clear,
arrow/Tab selection, inspect/evidence and bounded identifier entry. Paste cannot
execute commands. The optional control client shares those transitions; `0`
now applies there too, and a refused selector cannot change the filter.

The host had no immediate-input door. This movement adds a temporary terminal
byte carrier to the C seed through the existing wait effect, not another process
or opcode. Its named removal target and native replacement contract are in
`docs/glass-keyboard.md`. Key meaning stays in Form. This is not a claim that
the host effect or the C seed has disappeared.

Observed on this Mac: the real-PTY test passed 15 view/dialect transitions
without newline, plus split escape, bracketed paste, inspection, clean quit,
SIGINT/TERM/HUP restoration, suspension/resume and non-TTY refusal. One run's
maximum byte-to-controller transition was 1.6 ms; this is not full-frame paint
latency. Fresh preflight named zero compile errors and unresolved calls. The
input and launcher bands returned 65535; the UI band returned 4294967295; the
event-loop band returned 16777215, each with exit 0. Standalone import warnings
remain visible; whole-program compilation resolved their missing imports.

The live observer reading during the work was rows=165, recipes=91, asks=34.
Those attention requests remain; keyboard usability is not every organ healed.
No model admission, microphone activation or weights changed. The rented-turn
meter reported transcript-path-required, so no contribution percentage is claimed.

The useful surprise: quit had restored every terminal setting; Darwin additionally
set its PENDIN queue-state bit. The PTY witness now distinguishes that transient
state while comparing every actual setting. The awkward Enter requirement became
a real input path, with restoration tested as carefully as arrival.
