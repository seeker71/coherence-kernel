# Program-image native-waist unblock — 2026-09-02

The source-to-FKB emission proof had become a number-shaped false signal:
`program-image-tbl-emit.fk` called `value_kind`, but fkwu does not provide
that primitive. Its dependent emission band printed a full-looking number
while exiting `1`; preflight correctly named the call a lane seam.

The repair stays in the Form organ and its grammar mirror. `pite-int?` now
uses the existing exact decimal round trip, `int_to_str` then `str_to_int`,
to admit an integer stream. A string that looks numeric, `nothing`, and a
malformed value do not enter the stream. No runtime primitive, C seed,
flattening path, provider call, or artifact-loading behavior was added.

The existing band already carries the relevant hostile inputs: a string root
and a string node cell form otherwise-shape-valid tables and must render as
empty text. The repaired predicate makes both refusals observable while
valid negative and byte-row streams retain their exact golden text.
