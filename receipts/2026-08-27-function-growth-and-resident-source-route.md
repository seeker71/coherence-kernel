# The function seats dissolved; source and contribution entered the resident path

The resident Form peer can now route `source-concept` and `source-nodeid` tasks
through its existing Qwen state and KV residence. Generated raw bytes enter the
scannerless NodeID knowledge cursor; one exact persisted concept-key bucket
selects one bounded current source; its typed observation returns to that same
residence. Durable egress now names the route, callback count, tool status,
carrier, injected bytes, lifecycle, and lookup count without pretending every
cursor is a recipe cursor. Read-only retrieval remains contribution `0`; it does
not impersonate a landed mutation.

The first physical source turn exposed two detours. The peer initially composed
`fknsc-public-executor`, whose compatibility lane recursively walked the registry
inside `fk_walk` for more than twelve minutes. The strict routed executor already
existed; the peer now uses `fknqr-public-strict-executor`, where route absence is
typed evidence rather than permission for a global fallback. A warm full
6,548-source census plus the strict public query completed in 2.33 seconds.

Composing that already-built route exposed the temporary C seed's historical
`FK_FN_CAP=4096`. Removing another Form organ to fit would only have hidden the
same limit again. The seed now demand-grows function roots, arities, and three
source-symbol lanes geometrically as one organ. Numeric function indices remain
stable. Direct and indirect calls validate against the functions actually loaded;
`.fkb` import/load reserve from artifact-derived counts. No replacement fixed
function count was introduced.

This dissolves the capacity ceiling, not every lookup cost. The temporary seed's
source-name discovery still walks the present symbol rows linearly. That mapping
is now an observed performance/shrink seam rather than a hidden capacity law;
the northward identity is the Form/native NodeID relation, not a larger imposed
seat count or another C-owned dispatcher.

`form/scripts/fkwu-function-growth-test.sh` generated 5,000 leaf definitions and
a higher-order caller. The function above the old boundary returned `5000` from

The C movement is explicitly a checkout-witness repair and shrink target. It

## A guarded contribution transaction

`form-agent-repo-contribution.fk` adds the first bounded repository movement:

- capability data names root, allowed relative prefix, byte extent, and a test
  route NodeID;
- discovery and verification/testing are function values, not dispatcher seats;
- a proposal NodeID is interned from exact capability/path/old/new/test values,
  paying no SHA merely for bookkeeping;

- a failing post-test restores the recovery image;

## Resource truth learned during the crossing

The resident startup accepts an explicit external-MLX reservation because its
process-local Metal/MLX counters cannot see sibling processes. The first restart
was supplied `0` while a Claude-launched MLX LoRA training run was active. Metal
admission took 290,811 ms. The process census also found a Claude-launched
`source-of-band` still walking one CPU core after 56 minutes. No llama-server or
Ollama process was present. The orphaned band carried no unlanded source and was
stopped; the active LoRA training residence was left intact. The next residence
was supplied reservation `1`; a native system-wide resource sensor remains owed.

That residence replayed turns 1–3 in 18 ms, then entered the durable
`source-concept` turn. After roughly ten minutes at about one CPU core, no egress
frame had appeared and an OS sample located the work in recursively nested
`fk_walk`/`fk_walk_body`. The run was interrupted while its task spool remained
intact. Therefore the strict route is proven independently, but its present
composition with the resident model is not yet a healthy source contribution.

This is also the frontier-usage route: no new remote agent was opened for this
movement. Completed frontier audits changed the design once, then closed. Local
Qwen owns the physical source task; deterministic Form bands own verification;
frontier context is retained for gaps the local body cannot yet answer.

## Honest floor

The guarded actuator is proven on a bounded fixture, but the resident peer does
not yet parse a patch proposal frame and invoke it. Its recovery sibling is not
a crash-complete intent/preimage journal, and its test callback does not yet
execute any arbitrary repository band NodeID in-process. Recipe/turnwheel hot
swap is still absent. Mid-turn stage events are still too sparse: the first
linear-walk detour and the composed resident stall were localized by OS stack
samples, not by async Form stage events. The resident source route needs a
per-stage event around model emit, cursor completion, lookup, injection, and
post-observation decode before its recursion can be removed without guessing.
These are the next locally actionable joins.
