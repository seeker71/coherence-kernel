# A shared observed profile can speak without choosing a representative

Witnessed: 2026-08-09

## Claim boundary

This movement connects a current finite-space profile class to the existing
Form-native learned-surface membrane.  When every hypothesis retained by the
class has the same observed output at an exact offered binding, the class can
answer and voice that shared output without selecting or re-executing one
hypothesis as its representative.

The organ does not own a vocabulary, domain, answer set, timeout default,
preferred lens, or remote route.  The surface in this witness was supplied by
participants and learned through the existing consented symbol membrane.  The
movement is therefore native routing of learned meaning to learned surface,
not autonomous natural-language invention and not general NL-to-NL
translation.

## What moved

The preceding recursive witness retained two distinct executable hypotheses
inside one observed profile class over 100 offered points.  The new
`living-world-enquiry-profile-voice.fk` organ adds four live cells:

- a request naming the exact current class, exact bindings, offered symbol
  candidates, optional alternatives, optional unknown, optional choice,
  timeout, observed time, and evidence;
- an answer derived from the class's retained point field;
- a voice plan that matches current participant-learned surfaces to the shared
  output;
- an utterance retaining the class, both hypotheses, matching points, shared
  output, exact learned symbol and surface, immediate and effective
  acknowledgements, time state, options, witnesses, and evidence.

The answer path never chooses a hypothesis and never executes a Recipe.  It
reads the observed profile relation already held by the class.  Zero matching
points yields `NOTHING` now; one shared output yields `ONE`; multiple shared
outputs remain a plural `NODE`.  Surface planning separately yields no voice,
one voice, or plural voice candidates without installing a default.

## Nothing now is not timeout

The witness holds three states apart:

1. At a known profile point, the immediate acknowledgement is `ONE`, the time
   state remains pending, and one current learned surface can be voiced.
2. At a current binding outside the exact finite profile, the immediate
   acknowledgement is `NOTHING`, the time state remains pending, and there is
   no utterance.
3. At expiration, immediate `NOTHING` remains historically true while the
   sender-declared default condenses the effective acknowledgement to an
   `ALTERNATIVE` outcome.  That default cannot manufacture a profile point,
   output, learned surface, or utterance.

This preserves the difference between nothing observed now and the optional
response chosen by the sender when time expires.

## Freshness and revocation

Every request is current only while the request itself, its profile class, its
exact bindings, and its evidence remain current.  Answers, plans, and
utterances are reconstructed from that live world.  Withdrawing one required
offer for the class's enquiry space made both the class and the earlier
utterance non-current while retaining their historical cells.

Content identities below are freshness-stamped observations, never seals.
They name the exact version witnessed so later movement can be compared.  A
change creates a new identity and requires currentness to be reconstructed;
no hash freezes behavior, grants authority, canonizes vocabulary, or prevents
the organ from evolving.
