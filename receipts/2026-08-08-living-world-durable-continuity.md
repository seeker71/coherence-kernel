## Smallest native build

[`form/form-stdlib/cell-coordinate-stream.fk`](../form/form-stdlib/cell-coordinate-stream.fk)
is a registry-free, self-delimiting Form text carrier.  It preserves either:

- exact numeric category coordinates (`n`), or
- the exact source-native category string (`q`).

Ordered children and the presently supported integer, string, boolean, and
exactly re-internable finite-float leaves follow without guessed blueprint
names.  A source category is carried as identity, not translated through a
closed vocabulary or remote oracle.

[`form/form-stdlib/living-world-continuity-durable.fk`](../form/form-stdlib/living-world-continuity-durable.fk)
writes a candidate to an explicit `.pending` path, reads and canonically
decodes it, requires byte/text and semantic image equality plus the existing
manifest, renames it into place, then reads and verifies the final carrier.
Existing final or pending paths are refused rather than overwritten.  Loading
is inert: it does not restore authority, and any active restoration still
crosses the continuity organ's fresh unanimous holder-consent gate.

Result space remains open.  `ABSENT`, `REFUSED`, `INVESTIGATE`, and
`UNKNOWABLE` remain distinct from each other and from success.  Alternatives
and unknowable may independently be absent or present; neither is made
mandatory.  No timeout occurred in this witness, so no timeout-condensed
default was fabricated.

## Honest boundary

This carrier is a tree stream, not an authenticated compact DAG.  The active
file protocol is single-writer.  POSIX rename is atomic but not no-replace;
concurrent writers, hostile-input safety, cryptographic authentication,
signatures, cross-device rename, and crash durability through host storage are
not claimed.  Unsupported exact values return an open result rather than being
silently converted to nothing.
