## The native capability retained

`form-cli-review-bindings.bml` checks each finding's original field quotation,
caller-selected source quotation and corrected field quotation. It refuses
missing evidence, wrong-field quotations, unchanged fields claimed as applied
and replacements identical to the criticized text. It returns link counts,
never a semantic-quality score. Empty findings prove no correction.

The first live audit failed, exit 1:
`Review binding 1: replacement_quote is absent from its named corrected field`.
That exposed a flaw in the offered contract: it required replacement text even
when the model had actually deleted the criticized sentence.

The contract now supports explicit `operation="delete"`: the replacement must
be empty, the field must change, and the original quote must be absent from
that field. An empty replacement without this operation still fails. The
original report and failed audit remain immutable. A native helper proposed
one deletion marker in a separate candidate; it changed neither the answer nor
the next action. All six links then passed, as did the unchanged original
source and report assertions. This annotation is attributed to native checking,
not to the model, and establishes no additional semantic correction.

The boundary band preflight was clean and its verdict was 1, exit 0. Its
counterexamples include fabricated quotations, unchanged application, false
deletion and malformed rows. It deliberately accepts a real source quotation
paired with an unsound inference: entailment and completeness remain outside
the check. No C seed change or external runtime dependency was introduced.
