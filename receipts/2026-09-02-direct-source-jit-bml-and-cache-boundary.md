# Direct-source native admission now speaks BML

Date: 2026-09-02  
Surface: `form/form-stdlib/bml/direct-source-jit-discovery.bml`

## Movement

The executable direct-source JIT admission protocol has moved from a raw
S-expression cell into one high-grammar BML authority.  The compatibility
door, `form/form-stdlib/direct-source-jit-discovery.fk`, retains the existing
`dsjd-*` names so a caller does not need a second implementation or a
translation seam.

The BML authority carries the complete stateful protocol as data:

- caller-supplied meaning epoch + structural NodeID candidate;
- recursive discovery separate from native-page birth;
- explicit tied-hot `choice`, structural-identity `cut`, and exact unknown
  `nothing`;
- retained Form cold challenger beside every gate offer;
- native birth/reuse by the existing NodeID heat gate; and
- immutable before-gate projection for `undo`.

No candidate name opens source, filesystem, process, model, or Metal
authority.  The caller offers a lowerable program it already holds.  `0` and
`1` remain computed values, while refusal and timeout carry exact `nothing`.

## Cache boundary repaired

`form/form-stdlib/form-lower.fk` now declares its actual assembler dependency.
It can therefore compile as a complete standalone cacheable unit; before this
movement the direct unit reported 103 unresolved assembler calls, and an
importing run had to fall back from that degraded image.  This is source-level
dependency truth, not an expansion of the temporary C seed.
