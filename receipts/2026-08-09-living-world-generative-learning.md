# A native answer can learn from its observed outcome without self-promotion

Date: 2026-08-09

## The floor that moved

The live shared field could already receive transition and learned-surface
observations and reconstruct a Form-native continuation.  It still required
participants to author those observations directly.  An observed answer could
not itself reopen the field, become governed learning tissue, or describe the
next transition and expression evidence.

`living-world-generative-learning.fk` closes that missing bridge:

```text
exact current continuation trace
  -> independently offered outcome recurrence
  -> content-addressed learning-plan proposal
  -> unanimous feedback-holder acknowledgment
  -> inert transition-observation description
  -> explicit participant re-offer and transition tending
  -> inert expression-observation description
  -> explicit participant re-offer and expression tending
  -> locally reconstructed continuation
```

No step grants authority to the next one.  An integrated feedback plan cannot
write either observation into the world.  It only describes exact ordinary
cells that participants may re-offer through the existing shared-field
membrane.  Expression remains unavailable until the described transition has
independently become current.

## What an outcome may carry

An outcome contains only content-addressed material: its exact prior trace, an
optional expected link, an optional observed link, an optional arbitrary
coordinate, an optional exact surface, one four-arm acknowledgment, an
optional live lens declaration, alternatives, an optional unknowable
remainder, evidence, and its local path.

The organ contains no language tag, task name, answer class, vocabulary table,
surface literal, grammar, source preference, score winner, model route, host
I/O, or remote oracle.  Immediate `NOTHING` remains a valid outcome with no
learned transition.  A `NODE/ALTERNATIVE` can instead offer an observed link
without collapsing that history into `ONE`.  Contradictory acknowledgment and
payload identities are refused.

## Exact causal observation

The focused witness held one native request identity fixed.  Before feedback,
its trace contained zero turns and acknowledged `NOTHING`.  The same outcome
from one active source remained below recurrence threshold and produced no
proposal.  With two independent active sources, the framebuffer reported:

```text
witnesses:2:ack:3:transition:1:surface:1
```

Recurrence alone did not activate the plan.  After both holders acknowledged
the exact proposal, the framebuffer reported `active:1`.  The transition was
still inactive until both holders re-offered it and acknowledged its ordinary
transition proposal.  Only then could the plan describe the expression
observation; that cell likewise needed two re-offers and two acknowledgments.

After all four membranes settled, the unchanged request produced one terminal
turn and three rendered bytes.  Releasing one of the two original outcome
supports made the feedback plan stale, while the separately re-consented
transition and expression remained current.  Releasing both transition
supports then returned the request to zero turns and `NOTHING`.  This selective
staleness is the authority boundary: feedback does not own evidence that other
holders later consented to independently.

The comparison is aligned on the exact request and evaluation behavior, but it
is a same-sample learning replay, not held-out generalization.  It proves
evidence arrival and a native answer-state change; it does not establish a
general model-quality gain, a benchmark delta, or an unrestricted native
voice.  The repeated frozen `+733` benchmark remains unchanged and is not
renamed as movement.

## The framebuffer changed the design

The first run returned `958497/1048575`.  Its first feedback frame arrived
immediately and named `proposal:nothing`, locating the refusal before every
downstream stage.  A bounded diagnostic showed that all identities and active
attributions were current except the optional declaration.

The fixture had reused an arbitrary answer-alternative field as the lens
stack's unapplied-lens field.  That field may contain only lenses.  Separating
answer alternatives from optional lens alternatives restored the exact
contract; validation was not weakened.  The identical band then returned the
full verdict, with all five feedback framebuffer cells arriving within one
millisecond.

## Honest next edge

This movement metabolizes one consented answer outcome, but the observed
surface and link are still offered by participants.  The improved replay is
not held out, and no reusable structural species transferred the learning to a
different enquiry identity.

The next movement is to let admitted outcome plans become observations for the
already learned structural and behavioral species organs, then ask a
predeclared, identity-aligned held-out enquiry.  A quality claim becomes
admissible only if the held-out dataset and evaluation-contract identities stay
fixed while a newly admitted candidate derives the answer without having seen
that exact outcome.  Zero, one, many, silence, alternatives, and the unknowable
must remain distinct at that transfer seam.
