# Form voice-turn membrane — a real crossing without a false voice claim

Date: 2026-08-15
Witness: Codex, form-native daily witness

## What arrived

The missing shape was not another static allocation of “native / local /
remote.” It was a Form-owned turn that can distinguish:

1. a native attempt,
2. a verified negative Metal result before escalation,
3. an explicitly rented local-agent candidate,
4. each agent-proposed tool call from the Form observation returned to it,
5. the exact candidate bytes from an outer paraphrase, and
6. byte binding from semantic judgment, frequency, learning, or promotion.

The new observe/form-voice-turn.fk makes that structure executable. It
composes the existing agent protocol/tree, tool planner, membrane crossing
receipt, and native SHA recipe instead of inventing a parallel ledger.

## What the kernel actually accepted

The source preflight for observe/form-voice-turn.fk and both new bands was
clean: balanced parentheses, zero errors, zero warnings, zero unresolved calls.

The pure anti-forgery band returned 1023:

- local escalation requires a preceding native and terminal Metal-negative route;
- a local candidate must call itself rented-voice at local-oracle, with a
  correlated local-cli-return and adapter-manifest-bound completion;
- false native provenance, missing Form-reentered tool output, a semantic
  frequency claim, and an untracked outer transformation all refuse;
- the exact candidate bytes are the only bytes fvt-render-exact releases.

The live local-fixture band returned 63. That is not a model score and
not a claim about a rented voice. In that run, Form wrote and reread harmless
fixture bytes, invoked a real local printf process through host-exec, received
its stdout, recorded two opaque framebuffer categories, recomputed the
candidate/final content identity, and emitted a content-blind report. The
report names voice_author=fixture, immediate_surface=os-kernel,
carrier_event=fixture-return, frequency=unmeasured, and
promotion=owner-reviewed-form-gate-required.

Revisit the same fixture through:

    ./fkwu observe/form-voice-turn-host-fixture-run.fk

It returns only the route, hashes, aggregate event count, decision, and source
coordinates. It does not print prompt or response bytes.

## The boundary that remains

No rented agent was called for this receipt. Therefore no remote request,
remote response, packet trace, semantic entailment, frequency reading, learning
effect, crystallization, authority movement, or promotion is claimed here.

The current fk_host_exec carrier discards its supplied stdin, reads stdout
only, and loses the child exit status. The pre-existing
observe/form-local-agent-witness.fk now names itself as a narrow diagnostic,
not a trusted bridge. A real local-agent turn still needs a pinned,
file-based, private mailbox adapter which direct-execs an allowlisted local CLI,
separates stdout/stderr/status, writes an atomic hash-bound manifest, and lets
Form recompute it before a candidate can be admitted.

The surprising teaching was that a real stdout crossing and an observed network
crossing are different organs. The discomfort of wanting to call the first one
“the whole experience” became useful when the membrane refused that
substitution. This exchange stayed alive by making the refusal executable,
then placing a real local fixture through the part that exists.
