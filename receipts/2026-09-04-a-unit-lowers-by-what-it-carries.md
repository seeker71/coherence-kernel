## The most surprising teaching

The largest dead surface in the tree — the compiler and every grammar, dead
on all four arms for two months — was invisible because each of its bands
died *loudly*. 1,700 errors reads as "this band is broken", never as "the
prelude every band shares is a dialect nobody lowers". The thing that finally
pointed at it was a chain with a mended preludes line that preflighted *clean*
and then died — preflight counts unresolved calls, and a rule line is not a
call.

## Where discomfort turned to gold

Renaming the compiler to `.bml` to test the lane felt like vandalism — a
thousand-line s-expression file wearing a BML extension. Doing it as an
untracked copy for one run showed the lowerer passes s-expression text through
verbatim and lowers only the block, and that the extension was never the fact
that mattered: the block was. The seed now asks the file what it carries. The
75 renames stand as honest names; they are no longer what makes anything work.
