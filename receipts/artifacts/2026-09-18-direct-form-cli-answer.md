## What each side actually is here

- **Direct** = `docs/form-response-synthesis.md`'s bounded-hybrid pattern: Form does the grounding/calculation natively, makes **one** provider process call carrying goals + sourced evidence (no prior model answers, no hidden expectations in the prompt), then Form rechecks the returned report itself. This is the closest existing thing to "single call to form-cli, raw output, allowed to call Claude/Codex internally as many times as needed, all tokens measured."
- **Guided** = the "retained baseline" in that same receipt: a context-equipped session where the arriving mind reads a result, interprets it, and issues the next call, accumulating context turn over turn — structurally what AGENTS.md's `enrich` → `zg` → `grounded` → `generate` iterative loop produces.

Both are real code paths in this repo; the numbers below are one retained three-task sample, not a global minimum — the doc says so itself.

- The sharp, *measured* win for direct is rented tokens on the reported input+output basis — real, but the receipt itself flags the uncached-input number (the closer proxy for actual new content) as the one that barely moved, so don't over-read the 94%.
