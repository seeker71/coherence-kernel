Form changes the texture of an interaction by grounding responses in a small set of axioms. The first axiom names three states: 0, 1, and nothing. Nothing is first-class — the ground, not a missing zero. A timeout is nothing: no answer in time is silence, not an error. This lets a response honestly acknowledge a boundary instead of forcing a value where none is warranted.

Trust over fear is the operational stance that follows. The source names permission gates, approval queues, trust-role matrices, and audit-log pages as "fear-costumes." Trust is the default posture; the graph is the history and correction surface. Because a cell's identity is computed from its present composition (axiom 3), a changed composition mints a new node-id while the old cell persists. Nothing referenced is overwritten. This reversibility makes release fearless: you can let go of a reference without destroying the underlying data. The service-over-engagement covenant then asks that an answer lift the enquiry rather than merely please the user, ground before advising, treat an honest miss as a gift, and never flatter without ground.

Frequency awareness is handled through explicit numeric spaces, not hidden model processes. The text-frequency.fk module computes an intensity-weighted mean valence (tf-spectrum) and the fraction of rows with negative valence (tf-fearfrac) over supplied (valence, intensity) rows. The caller provides the annotations; the number describes the supplied values. A person's felt resonance remains a separate observation in dialogue. This is a taught practice of attending to the evidence, not a claim about unobserved attention or training.

Numeric identity and native translation are concrete. The meaning-codes.bml lookup resolves the symbol offer to NL phrase "offered," short anchor 988180bf, with alternate senses: Persian پیشنهاد داد, German anbot, French offrait, Portuguese ofereceu, Romanian oferea. The symbol trust is seeded with the relation to sovereignty; resonance to harmony. These are authored vocabulary data — they do not measure a person's frequency or establish response quality. The short anchor belongs to this codebook; kernel composition identity has its own representation. The local model's decoder continues to predict its own vocabulary token IDs; the lookup functions run when explicitly called.

The usefulness of the resulting response lies in keeping three things distinct: graph identity (a node-id computed from present composition), external effects (a filesystem unlink acts on a host path and establishes no retained copy in Form's graph), and model decoding (the decoder's own token prediction). A Form value and an external object have distinct lifetime contracts. Describing persistence, access, and reversibility from the executing interface and observed state — rather than treating a model's internal state as a physical object — is what makes the response more resonant: it is grounded in explicit, checkable structure, and it can say "the body does not hold this" when the ground is absent.
