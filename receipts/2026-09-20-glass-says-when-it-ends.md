# Glass says when it ends

2026-09-20, this Mac. Glass was asked for and glass was down. What follows is
what was observed, what was healed, and what is still unknown.

## What was there to find

No glass process was alive at 19:13. `.hearth/form-glass-supervisor.state` read
`running`. The ear's owner file named pid 1373; that pid was gone, and no ear
lane stood. This Mac booted at 09:17 (`kern.boottime`); glass carries no launch
agent, so the boot ended it and nothing stood it again. For the ten hours
between, every reader of that state file was told an organ was alive.

## The first stand, and its own evidence

Stood again from the main checkout, glass bootstrapped, admitted, drew its first
frame at 41x61 — and ended inside the first tick:

```
ear ? unread | fkwu: order: only numbers have an order -- ask value_kind before lt/le/gt/ge
[glass-supervisor, live-exit, 1]  → Glass live runner failed; owned sensors released
```

The second stand ran clean, and has kept running. Four reproductions afterwards
found nothing: the four views render at 41x61, the live runner alone stands at
41x61 under a pty, and the whole fleet ran twenty seconds headless without a
refusal. The ordering that ended the first stand cleared itself when the carrier
released its sensors, and it left no site behind. It is named here as not found.

## What was healed

The state is a pulse rather than a wish. `fglu-supervisor-mark` writes the word,
the pid that beats it and the moment of the beat; `fglu-supervisor-standing?`
asks `host_alive` before believing `running`. A word whose keeper is gone now
reads as what it is.

Every ending speaks. Admission refused, live runner exited, carrier ended: each
writes an `organ-health-v1` reading to `.hearth/organ-health.jsonl` and voices
it, carrying what it needs and what it offers — restart the glass, inspect the
reported unit, abstain. The spool outlives the terminal the glass was watched
in, which is where the earlier ending went and was lost.

The live organ took the healing by itself: the dependency manifest changed, the
supervisor was reborn, and the state file now reads `running|pid=7554|beat=...`
with that pid alive.

## The signal was nearly mute

Before this landed, one call of the new reading was asked to speak outside the
organ. It refused: `organ health event has no complete identity or observation`.
`oh-voice` answers its own printing, not the row it spoke, so the ending was
handing an integer to `oh-emit` — the signal would have thrown inside the very
path meant to carry the failure, and glass would have ended twice as quietly as
before. The row is held first now, then voiced, then kept, and a complete
`organ-health-v1` row lands. The same shape read correctly elsewhere through
`oh-voice-all`, which does answer its rows.

## What this does not establish

The ordering refusal has no named site; the next one will carry the live
runner's exit into the spool instead of into a closed terminal. Nothing here
gives glass a keeper across a boot — it is still stood by hand.

## Receipt

The surprise: the crash healed the condition that caused it, so the only thing
left ten hours later was a file that lied. The lie outlived the wound, and the
lie was the greater harm — a body reading that file had no reason to look.

Discomfort into gold: wanting the exact failing line and not finding it, four
reproductions deep. Witnessed rather than argued away — named as not found, and
the wanting turned into the signal that will name it next time.

And the second turn of it: the one call that proved the new signal could speak
is what caught it mute. A signal added to an error path is worth exactly what it
says when that path runs, and nothing before.

Frontier question, answered by the rented mind and offered to the corpus:
**what is a state whose keeper is gone but whose word still stands?**
**keeperless** — a word left standing over an organ that ended, read as present
by everyone after it. The repair is not to write the word more carefully but to
write the keeper beside it, so the reading can ask whether it still beats.
