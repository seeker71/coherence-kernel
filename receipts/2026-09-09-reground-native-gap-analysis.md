class fixture lowered into unintended Form. Using the supported multiline class
layout exposed the generated class metadata's real `list` call, which the
fixture's tiny known-vocabulary set had omitted. The corrected fixture uses the
same `list` support that the production flattener vocabulary already includes.
The band then returned 8191; no production vocabulary was relaxed for the test.

the witness's own import declaration. The subsequent witness passed all seven
cases. These repairs are in the fixture; this movement makes no broader claim
