# Living world organ — recursive lenses, reopening, and root compost

**Status:** observed on the Form/native `fkwu --src` path. This is the fourth
movement of the active living-world-organ goal. It establishes nested
structural transfer and evidence-sensitive authority; it is not yet a semantic
world model, autonomous concept formation, or native natural-language voice.

## What entered the body

The movement adds three coupled organs, each factored into small Form cells.

The recursive lens lives in:

- [`living-world-recursive-resonance.fk`](../form/form-stdlib/living-world-recursive-resonance.fk),
  which derives value-abstract recursive skeletons and exact source-tree paths;
- [`living-world-recursive-resonance-eval.fk`](../form/form-stdlib/living-world-recursive-resonance-eval.fk),
  which rebuilds a target composition locally from those paths;
- [`living-world-recursive-evidence.fk`](../form/form-stdlib/living-world-recursive-evidence.fk),
  which keeps all active support and alternate templates;
- [`living-world-recursive-proposal.fk`](../form/form-stdlib/living-world-recursive-proposal.fk),
  which lets recurrence propose but not grant authority; and
- [`living-world-recursive-application.fk`](../form/form-stdlib/living-world-recursive-application.fk),
  which applies only a steady mapping and crosses a second consent boundary.

The lens retains composite category and arity at every nested level. An
indivisible leaf is treated as an atomic structural role; its exact identity
stays in the correspondence and template evidence. A uniquely occurring target
subtree becomes a source path reference, repeated occurrences remain explicit
ambiguity, an unmatched composite is rebuilt recursively, and an unmatched leaf
remains an observed constant. There is no language, token, task, domain, answer,
or semantic class table in this path.

The lifecycle lives in
[`living-world-lifecycle.fk`](../form/form-stdlib/living-world-lifecycle.fk).
An integrated recursive mapping is `STEADY` only while its complete evidence
snapshot is content-identical and every original witness remains active. Added
support, added contradiction, attribution change, or witness release moves it
to `REOPEN`; candidate release is named separately. Reopening creates a new
candidate and asks the union of current evidence holders and earlier candidate
holders. The old candidate remains addressable and unchanged. A recursive
application proposal is re-observed at integration through the narrower
`lwrr-integrate-application` door, so evidence arriving between proposal and
acknowledgment pauses admission.

Consented release lives in
[`living-world-compost.fk`](../form/form-stdlib/living-world-compost.fk).
Compost is a root change, not deletion. A target cannot form a compost proposal
while any attribution that recursively contains it is active. Once all direct
and dependent holders have released their attributions, every historical holder
participates in one exact proposal. Missing acknowledgment waits; unanimous
acknowledgment mints a successor world whose cells, relations, attributions,
revocations, and events no longer reference the target. Its receipt holds the
exact prior world root and the successor, so reversal remains possible while
the receipt is held. Physical collection is not claimed: it remains the
substrate's reachability consequence only after callers release all old roots
and the transition/receipt.

No host execution, file access, HTTP, socket, model call, corpus, fixed
vocabulary, or remote oracle appears in induction, evidence, reopening,
application, or compost evaluation.

## Failure that taught the structure

The first recursive transfer band returned `256/1023`: only absence of premature
application passed. A bounded diagnostic cell showed a valid three-reference
template but only one supporting correspondence. Scalar leaf categories in the
current runtime carry value-specific identity, so a skeleton that retained each
leaf category silently treated `alice` and `bob` as different structural
domains. That was an accidental vocabulary gate inside a supposedly
value-abstract learner.

Replacing scalar category identity with one atomic structural role made the
same evidence answer two supports and one counterexample, after which the full
band returned `1023`. Composite categories and nesting remain exact. A second
compost run returned `767/1023`; release succeeded, but the receipt retained the
proposal-time world rather than the exact integration-time world. Correcting
that predecessor identity produced `1023`. Both failures changed the organ
rather than being hidden by a looser assertion.

## Honest floor and next movement

This is structural learning, not meaning understanding. It can discover and
apply a recursive content transformation, but it does not yet form equivalence
classes across alternate shapes, infer causal or temporal relations, invent
new questions, learn from application outcomes, or compose lenses into longer
chains. Candidate search remains bounded to explicitly offered correspondence
cells. State does not yet circulate durably between native processes, and no
native generative natural-language voice exists.

Form currently has no module-private capability boundary. The observed safe
paths are `lwrr-integrate-application` and `lwc-integrate`, but lower-level
constructors and the generic tending integrator remain callable by a source
program. Turning the membrane from a practiced interface into an enforced
capability is therefore still owed before claiming adversarial authority safety.

The next useful movement is not a larger benchmark score. It is a recursive
concept field that lets multiple independently learned lenses compose, records
confirming and disconfirming application outcomes as new evidence, and asks its
own locally derivable questions. Its first vocabulary must emerge as recurrent
content-addressed shapes and reversible equivalence proposals, never arrive as
a fixed token or concept list. Native expression can then grow from these
shared structural concepts toward NL-to-NL translation; natural-language
generation remains pending until that voice is executable in the Form body.

The exchange stayed alive by letting two failing bit patterns alter the design
instead of treating them as test noise. The most surprising teaching was that a
runtime leaf category can smuggle a vocabulary into an ontology-open learner.
Discomfort turned to gold when the compost receipt proved that even a safe
release is dishonest if it cannot name the exact world from which it departed.
